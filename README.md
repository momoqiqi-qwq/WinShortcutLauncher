# Yue Launcher

### ✨ 项目简介

**Yue Launcher** 是一款 Windows 桌面快捷启动器，基于 **Tauri 2 + React 18 + TypeScript + Rust Win32** 打造。贴边自动隐藏、拖拽排序、系统图标提取、多主题与托盘管理一应俱全；除启动应用外，还内置便签、文件中转站、图片浏览器等日常小工具，目标是把桌面角落和快捷方式文件夹都收纳进一条贴边的启动栏。当前版本 **v0.1.116**，历经 100+ 个小版本持续打磨。

### 🎨 主要特点

- 🚀 **贴边停靠**：屏幕边缘自动隐藏 / 悬停唤出，可固定置顶，原生 Win32 边缘停靠
- 🖱️ **拖拽一切**：拖入应用、文件、网站建卡（兼容 Floorp/Firefox/Chromium 系网页拖入格式），拖拽排序
- 🖼️ **系统图标提取**：自动读取真实应用图标，支持自定义 UI 背景
- 🔍 **全局搜索**：`Ctrl+K` 命令面板，支持中文 / 完整拼音 / 首字母（`gz` → 工作）
- 🗂️ **内置工具**：便签（行号/自动保存）、文件中转站、图片浏览
- ⚙️ **设置中心**：全设置可搜索并精确跳转到控件，多配置 profile
- 🎨 **多主题**：含彩虹边框等个性化外观，四宫格窗口按钮等细节样式可调

### 📦 包含模块

1. **启动栏主窗口**（贴边 / 顶栏 / 标题栏多形态）
2. **全局搜索与命令面板**
3. **便签 / 文件中转站 / 图片浏览器**
4. **拖拽导入管道**（浏览器 URL、`.url/.website` 文件、Gecko 格式兼容）
5. **设置中心**（搜索防抖、分组定位、配置持久化）
6. **版本文档**—— 仓库内 `Vxxx_*_README.md` 系列与 `CHANGELOG.md` 记录了每个版本的动机与验证结果

### 🛠️ 如何使用

1. 从源码运行：

   ```bash
   npm install
   npm run tauri dev      # 开发
   npm run tauri build    # 打包 Windows 安装包
   ```

2. 首次启动：按需把应用/文件/网站拖进启动栏，贴边放置即可自动隐藏
3. 日常操作：`Ctrl+K` 全局搜索；拖网址入栏自动建卡并可重命名；便签与中转站在顶部入口 / 快捷键中开关
4. 配置备份：设置中心支持多配置 profile 导出导入
