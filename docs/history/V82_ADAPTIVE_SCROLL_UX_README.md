# Yue launcher v82：设置自适应滚动保护与浏览体验优化

## 1. 设置窗口空间不足时自动显示滚动条

当“设置 - 界面 - 自动适配 exe 主界面大小”开启后：

- 设置窗口继续跟随主界面大小；
- 当可用宽度不足时自动显示横向滚动条；
- 当可用高度不足时自动显示纵向滚动条；
- 不再裁掉右侧设置、底部按钮或说明文字；
- 小窗口会自动减少标题、导航和设置卡片的间距。

设置标题会显示“自适应”和“滚动保护”状态，底部也会提示当前是否因为空间不足启用了滚动保护。

## 2. 设置浏览体验优化

- 每个设置分类可以分别记住上次滚动位置；
- 在“设置 - 体验”可以关闭滚动位置记忆；
- 页面向下滚动后显示“顶部”按钮，可快速回到当前分类顶部；
- “设置 - 界面”新增“重置布局”，可清除设置窗口位置、大小和分类滚动记录；
- 设置搜索新增“自适应、重置布局、滚动位置”等关键词；
- 自适应小窗口会自动进入紧凑显示，减少不必要的占用。

## 3. 代码结构优化

设置窗口大小、拖动、缩放、布局恢复、溢出检测、滚动位置记忆和返回顶部逻辑已从 `SettingsPanel.tsx` 抽离到：

```text
src/components/Settings/useSettingsPanelLayout.ts
```

自适应尺寸和滚动判定的纯函数位于：

```text
src/lib/settingsPanelBounds.ts
```

这样后续修改设置页内容时，不需要同时触碰窗口几何和滚动逻辑。

## 4. 配置迁移

新增体验设置：

```text
rememberSettingsScrollPosition
```

默认开启。旧配置会自动补齐，不影响原来的父目录、子目录、项目、便签或其他设置。
