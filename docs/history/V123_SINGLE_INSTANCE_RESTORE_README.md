# V123 - 再次运行自动取消隐藏

## 行为

- 应用已经运行且主界面隐藏到托盘时，再次运行 EXE/快捷方式不会启动第二个实例。
- 第二次启动会通知现有实例，复用 `show_main_window()` 自动取消隐藏、恢复窗口尺寸/位置并聚焦。
- 如果窗口处于贴边自动隐藏状态，再次运行同样会触发已有的 `edge-force-show` 恢复逻辑。
- 应用本来已经显示时，再次运行只会把现有窗口显示并聚焦，不会创建重复实例。

## 实现

- 新增官方 `tauri-plugin-single-instance`。
- 插件按 Tauri 官方建议作为第一个插件注册。
- 单实例回调直接调用现有 `show_main_window()`，避免复制托盘恢复和贴边恢复逻辑。
- 版本号更新为 `0.1.123`。
