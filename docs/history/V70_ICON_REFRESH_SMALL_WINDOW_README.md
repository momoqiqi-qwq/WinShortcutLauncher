# v70 图标强制刷新 / 单项目刷新 / 异常小窗口恢复

## 修改内容

1. 刷新本页图标改为强制刷新
   - 不再因为项目已经有图标而继续显示旧缓存。
   - 本地保存的网站 favicon 会使用新的缓存文件名，确保已有图标也重新载入。
   - 不保存到本地时，会给在线 favicon URL 添加刷新参数，绕过 WebView/HTTP 缓存。
   - “全部”标签中的刷新本页图标会刷新当前可见的全部普通项目。

2. 项目右键菜单新增“刷新当前项目图标”
   - 只刷新当前右键项目，不刷新本页其他项目。
   - 网址项目按设置中的 favicon 来源、自动保存和兜底策略刷新。
   - 文件、文件夹和命令项目会重新提取源路径图标。

3. 异常小窗口恢复
   - 启动时检查保存的主窗口大小。
   - 宽度或高度任一小于 250 像素时，不恢复异常尺寸，改为默认 1180 x 880。
   - 新电脑或没有窗口记录时也使用 1180 x 880。

## 验证

- `npm run build` 前端构建通过。
- 当前环境没有 Cargo，Rust/Tauri 原生命令需在 Windows 本机完成最终编译验证。
