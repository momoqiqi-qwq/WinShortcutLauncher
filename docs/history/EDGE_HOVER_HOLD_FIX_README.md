# 贴边窗口鼠标停留保持展开修复

本次修改针对贴边自动隐藏交互：

- 鼠标仍在主窗口界面内时，贴边窗口保持展开，不启动自动隐藏倒计时。
- 点击按钮、菜单或其它界面控件时不会因为点击动作自动缩回侧边。
- 鼠标真正离开主窗口后，才重新从头计算原有的“贴边隐藏延迟”。
- 从隐藏触发条展开后的既有保护逻辑保持不变。

## 实现方式

核心判断放在 Rust 原生贴边轮询 `src-tauri/src/edge_dock_native.rs` 中，直接复用原本每轮已经读取的 Win32 鼠标坐标和窗口矩形，不新增前端事件桥接、定时器或 Store 更新。

因此该修改不会因为鼠标移动频繁触发 React 重渲染，也不会增加 Tauri invoke 调用频率。

设置页 `src/components/Settings/BehaviorSettingsSection.tsx` 同步增加了行为说明。
