# v0.1.106 父目录配色、外观自由度与拖入体验

## 本版目标

这一版延续 v0.1.105 的“设置自由度”方向，重点让顶部父目录不只是普通标签，而是可以作为清晰的彩色分组入口，同时让用户在设置中心直接管理父目录颜色和外观。

## 新增功能

### 1. 父目录配色进入设置中心

位置：`设置 -> 导航 -> 父目录配色`

支持：

- 每个父目录单独选择颜色；
- 六个常用色板快捷按钮；
- 一键彩色分组；
- 一键换一组颜色；
- 一键清除所有自定义色，让父目录重新跟随主题；
- 单个父目录随时恢复“跟主题”。

批量配色使用 `setGroupColors` 一次更新整个 store，不再为每个父目录连续触发一次状态更新。

### 2. 父目录标签新增更多外观设置

位置：`设置 -> 界面 -> 父目录标签`

新增：

- 标签高度；
- 标签间距；
- 标签文字大小；
- 边框粗细；
- 自定义颜色填充强度；
- 原有等宽宽度和圆角/方形继续保留。

增加四个一键预设：

- 紧凑；
- 标准；
- 彩色卡片；
- 醒目。

预设只改变标签外观，不会修改父目录名称、排序或各父目录已经保存的颜色。

### 3. 拖入父目录反馈更明确

外部文件、文件夹或网页拖到顶部父目录时：

- 目标父目录会高亮；
- 拖拽遮罩会显示“松开鼠标添加到「父目录名」”；
- 文件导入窗口会优先选择目标父目录里的普通子目录；
- 网页会直接添加到目标父目录的普通子目录；
- 如果目标父目录只有便签/“全部”等特殊页而没有普通子目录，会自动建立“常用”普通子目录接收内容。

### 4. 设置搜索补齐

现在可以直接搜索：

- 父目录配色；
- 彩色分组；
- 父目录背景色；
- 标签高度；
- 标签间距；
- 标签字体；
- 标签边框；
- 颜色强度。

## 代码结构调整

新增独立模块：

- `src/components/Settings/ParentGroupAppearanceControls.tsx`
- `src/components/Settings/ParentGroupAppearanceControls.css`
- `src/components/Settings/ParentGroupColorSettings.tsx`
- `src/components/Settings/ParentGroupColorSettings.css`

另外将 `NavigationSettingsSection` 与 `ExperienceSettingsSection` 重复实现的开关卡片抽到 `SettingsPrimitives.tsx` 的 `ToggleCard`。

这样新增的父目录设置没有继续堆进 2700+ 行的 `Settings.css`，也避免继续扩大 `DisplaySettings.tsx` 的 JSX 复杂度。

## 兼容性

- 旧配置没有父目录颜色时保持原来的主题效果；
- `Group.color` 为可选字段；
- 配置恢复时仅接受 `#RGB`、`#RRGGBB`、`#RRGGBBAA`，异常颜色会被忽略；
- 新增的父目录外观字段都有默认值并在恢复时进行范围限制。
