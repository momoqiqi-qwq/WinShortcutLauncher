# v54 便签行号跳转与浏览器拖拽网址

## 修改内容

1. 便签行号点击跳转增强
   - 点击左侧行号时，光标定位到当前便签对应行。
   - 如果点击的行号超过当前便签已有行数，会自动补充空行到该行。
   - 行号栏会根据可见编辑区域补足空白行号，方便直接点击空白区域对应行。

2. 浏览器拖拽网址到 exe 界面
   - 支持从浏览器地址栏/链接拖动网页到软件窗口。
   - 松开后自动添加为网址项目到当前普通子目录。
   - 当前在“全部/便签”等特殊目录时，会添加到当前父目录下第一个普通子目录。
   - 自动按设置中的图标选项获取 favicon。

3. 版本更新
   - package/tauri 版本更新到 0.1.54。
