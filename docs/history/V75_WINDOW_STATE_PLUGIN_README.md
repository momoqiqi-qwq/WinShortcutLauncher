# v75 窗口大小手动保存 / 启动恢复 / 关机保存

## 设置 - 操作

新增“窗口大小保存与恢复”折叠分组：

1. **使用手动保存的当前界面大小**
   - 开启后可点击“保存当前大小和位置”。
   - 保存主窗口的宽度、高度、位置和最大化状态。
   - 手动快照独立于退出/关机快照，不会被后者覆盖。
   - 可随时清除手动快照。

2. **启动应用时自动恢复保存的大小**
   - 开启：按优先级恢复窗口。
   - 关闭：每次启动使用默认 `1180 x 880`。

3. **退出应用或系统关机时自动保存**
   - 使用官方 `tauri-plugin-window-state` 保存大小、位置和最大化状态。
   - 隐藏到托盘不算退出，不会更新退出/关机快照。

## 恢复优先级

```text
手动保存 > 退出/关机自动保存 > 默认 1180 x 880
```

即使退出/关机时又保存了当前窗口状态，只要“使用手动保存的当前界面大小”已开启且手动快照存在，下次启动仍优先使用手动快照。

## Rust 侧恢复

- 主窗口在 `tauri.conf.json` 中以 `visible: false` 创建。
- Rust `setup` 阶段先恢复状态，再显示窗口，减少启动时先显示默认大小再跳动的问题。
- 官方插件只管理主窗口，自动状态文件使用 `.window-state-auto.json`。
- 手动快照和三个开关分别保存在应用配置目录，避免依赖 WebView localStorage 才能决定启动尺寸。
- 删除了旧的前端 `useRememberWindowBounds` 自动保存逻辑，避免前端和 Rust 同时争抢窗口大小。

## 异常尺寸保护

- 手动快照小于 `250 x 250` 时不会保存。
- 自动快照恢复后若任意一边小于 250，会退回默认 `1180 x 880`。
- 保存位置不在当前任何显示器上时，会把窗口居中显示。

## 版本与迁移

- 程序版本：`v75 / 0.1.75`
- Zustand 持久化版本：`6`
- 旧版 `rememberMainWindowBounds` 会迁移为“启动恢复 + 退出保存”，不会清空现有项目或便签数据。
