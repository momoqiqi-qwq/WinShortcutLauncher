# v0.1.99 动态壁纸、预览与快捷设置

## 1. 背景媒体

主界面和设置界面使用同一套背景媒体组件，但保存独立配置。支持：

- 静态图片：PNG、JPG/JPEG、BMP、SVG、WebP。
- 动态图片：GIF、APNG、动态 WebP。
- 视频壁纸：MP4、WebM、OGV/OGG。
- 网络地址、Data URL、Blob URL，以及通过文件选择器导入的本地文件。

通过“浏览”选择本地文件后，Tauri 后端会校验扩展名，并把文件复制到应用数据目录的 `wallpapers` 子目录。配置中保存副本路径，降低源文件移动、改名或删除造成的失效概率。

## 2. 适应方式与画面焦点

提供四种适应方式：

- 裁切铺满：保持比例并填满界面，超出部分裁切。
- 完整显示：完整保留画面，可开启柔化填充留白。
- 拉伸铺满：忽略原比例铺满。
- 原尺寸平铺：仅针对图片；视频会按裁切铺满处理。

画面焦点可以通过三种方式调整：

1. 九宫格快速定位。
2. 水平和垂直滑块精调。
3. 在实时预览中单击或拖动十字焦点。

同时可调整背景可见度、压暗、模糊和内容面板不透明度，使文字和图标在亮色壁纸上仍保持清晰。

## 3. 动态播放与性能

- 视频默认循环、静音、内联播放。
- 支持 0.25×～2× 播放速度。
- 默认在窗口隐藏、失焦或页面不可见时暂停视频。
- 开启“减少动态效果”时不自动播放视频。
- GIF、APNG 和动态 WebP 由浏览器图片解码器播放，当前版本不能单独暂停或调速。

## 4. 设置窗口背景

设置窗口可使用独立背景，并提供：

- 独立图片/视频、焦点、适应方式和动态播放参数。
- 独立面板不透明度。
- 可选玻璃感，包括半透明、背景模糊和边缘层次。
- 独立实时预览，不需要反复关闭设置观察效果。

## 5. 右上角快捷入口

右上角新增滑杆图标按钮。菜单可直达：

- 界面 → 主界面背景与动态壁纸。
- 界面 → 设置界面背景。
- 字体。
- 快捷键。
- 图标。
- 体验。

菜单支持点击外部或按 Esc 关闭。按钮也进入窗口按钮排序、样式和隐藏设置，可按个人习惯调整位置或隐藏。

## 6. 兼容与清理

- 旧版 `backgroundPosition` 会迁移成水平/垂直焦点。
- 异常的媒体类型、适应方式、数值范围和路径会在读取时归一化。
- 旧配置中的自定义命令、动作链、自动化和相关日志会在迁移时移除。
- 全局命令面板不再加载已移除的动作链数据，并对损坏的旧条目做防御性处理。

## 7. 下一版本建议

建议 v0.2.00 优先考虑：

1. 壁纸库、收藏、播放列表、定时和随机切换。
2. 可视化裁剪框、缩放，以及不同父目录使用不同壁纸。
3. 跟随 Windows 系统壁纸，并完善多显示器策略。
4. 电池模式、低功耗帧率和视频解码资源提示。
5. 壁纸缓存管理，包括占用空间、失效文件和一键清理。
