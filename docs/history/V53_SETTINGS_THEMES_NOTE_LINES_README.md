# v53 - 设置缩小修复 / 更多主题 / 便签行号范围与跳转

本版基于 v52 继续修改：

1. 修复设置界面自己缩小
   - 设置浮窗 ResizeObserver 不再使用 contentRect 保存尺寸。
   - 改为保存 border-box 尺寸，避免每次观察都少算边框导致窗口一点点变小。

2. 更多主题与更密集主题卡片
   - 新增多套深色、浅色、霓虹、柔和办公主题。
   - 外观和更多主题的主题框变小，信息更密集，能一次看到更多主题。

3. 便签行号范围
   - 设置 - 便签 - 编辑器显示 添加“行号开关范围”。
   - 可选择“所有便签共用”或“当前便签单独保存”。
   - 当前便签模式下，便签右上角行号按钮只影响当前便签。

4. 点击行号跳转
   - 显示行号时，点击左侧对应数字会跳转到对应行。
   - 跳转后光标会定位到该行开头。
