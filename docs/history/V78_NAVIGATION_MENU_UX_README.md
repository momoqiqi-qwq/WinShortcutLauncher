# v78 子目录右键菜单与导航体验优化

## 1. 左栏子目录右键菜单

截图中的“添加文件 / 添加文件夹 / 添加网址”菜单顶部新增“新建子目录”。

- 普通子目录中可以直接新建。
- “全部”特殊入口中保持禁用，避免破坏既有特殊标签规则。
- 新建行为与左侧顶部“新增子目录”按钮共用同一套逻辑。

## 2. 设置 - 导航与菜单

新增独立设置分类：

- 右键子目录默认打开：添加项目 / 管理目录。
- Ctrl、Shift 或 Win + 右键临时打开另一种菜单。
- 新建前询问名称。
- 新建后自动进入。
- 重名时自动编号。
- 双击侧栏空白处新建。
- 子目录后显示项目数量。
- 右键菜单紧凑模式。
- 右键菜单显示功能图标。
- 菜单顶部显示当前子目录。

提供“推荐效率 / 紧凑快捷 / 管理优先”三个快速预设。

## 3. 细节优化

- 新建目录 action 返回新目录 ID，界面可可靠地立即切换到新目录。
- 当前激活的子目录自动滚动到可见位置。
- 重名目录使用不区分大小写的自动编号，例如“工作 / 工作 2 / 工作 3”。
- 子目录数量规则：普通目录为项目数，便签为行数，“全部”为普通目录项目总数。
- 右键菜单可显示当前目录标题，减少在多个目录间操作时选错目标。

## 4. 数据兼容

- localStorage 名称、配置导入导出结构保持不变。
- 持久化版本从 8 更新到 9。
- 旧配置通过 normalizeExperience 自动补齐新字段。
