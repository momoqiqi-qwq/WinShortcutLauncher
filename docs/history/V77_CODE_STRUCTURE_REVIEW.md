# v77 代码结构检查

## 本次已经优化

- `SettingsPanel.tsx`：约 1326 行降到约 203 行。
- 设置分类内容改为独立组件，减少单文件职责。
- 快捷键解析、规范化、事件匹配、冲突检测集中到 `lib/keyboardShortcuts.ts`。
- 快捷键状态通过现有 settings slice 管理，并接入导入、导出、默认值、迁移和持久化。
- 项目页、设置页、全局搜索和主窗口统一读取同一套快捷键配置。

## 后续仍值得优化

1. `BehaviorSettingsSection.tsx` 约 360 行，可继续拆为贴边、窗口状态、触发条、启动关闭四个组件。
2. `App.tsx` 约 746 行，仍同时负责浏览器拖入、浮层状态、全局快捷键、贴边暂停和通知。
3. `Settings.css` 较大，适合按基础布局、各分类和快捷键页面拆分 CSS 文件。
4. Rust 窗口与贴边逻辑仍较集中，适合在后续版本统一成窗口状态机。

## 推荐下一步

优先做“全局交互控制器拆分”：把 `App.tsx` 的快捷键、浮层、浏览器拖入和通知分别抽成 hooks。风险低于直接重写贴边逻辑，也能继续降低以后新增功能时相互影响的概率。
