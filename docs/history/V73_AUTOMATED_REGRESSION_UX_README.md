# v73 自动化回归测试与体验优化

## 自动化回归测试

新增 Vitest 测试框架与以下命令：

- `npm test`：执行一次全部回归测试。
- `npm run test:watch`：监听源码变化并自动重跑测试。
- `npm run verify`：先执行回归测试，再执行 TypeScript 与 Vite 生产构建。
- `验证回归测试.bat`：Windows 双击执行测试与前端构建。

当前包含 8 个测试文件、25 个测试，覆盖：

1. favicon 主域名归并与同站点缓存复用。
2. “刷新本页图标”只补齐缺失图标，不覆盖已有图标。
3. 保存窗口小于 250×250 时恢复 1180×880。
4. 项目固定、名称、最近启动、最常使用排序。
5. Maye/Maya JDB JavaScript 与 Lucy 便签导入。
6. 体验设置默认值与旧配置补齐。
7. 设置分类关键词搜索。
8. 配置自检：重复 ID、空路径、异常网址、重复路径与缺失图标。

新增 `.github/workflows/regression.yml`：

- Linux 自动执行 `npm run verify`。
- Windows 自动执行前端测试和 `cargo check`。

一键构建脚本也改为先执行测试，测试失败时不会继续打包 EXE。

## 用户体验优化

### 设置新增“自检”

- 显示父目录、子目录、项目、便签、网址、缺失图标数量。
- 检查重复 ID、空名称、空路径、异常网址、重复项目路径与缺失图标。
- 支持重新检查和复制诊断摘要。
- 自检只读取数据，不会自动修改或删除项目。

### 设置搜索增强

- 不再只匹配分类名称。
- 支持搜索“favicon、回弹、行号、分界线、缓存、开机、托盘”等功能关键词。
- `Ctrl+F` 在设置界面中直接聚焦设置搜索框。
- 搜索结果会自动切换到第一个匹配分类。
- `Esc` 先清空设置搜索，再关闭设置窗口。

### 提示气泡增强

- 支持点击关闭。
- 增加自动消失进度条。
- 长提示自动省略，鼠标悬停可查看完整内容。
- 新提示会安全替换旧提示并重新计算显示时间。

## 代码结构整理

- 把体验设置默认值与迁移规则移入 `lib/experienceSettings.ts`。
- 把窗口尺寸清洗和屏幕范围限制移入 `lib/windowBounds.ts`。
- 把本页图标补齐规则移入 `lib/pageIconPolicy.ts`。
- 把设置关键词搜索移入 `lib/settingsSearch.ts`。
- 新增 `lib/configDiagnostics.ts`，统一配置健康检查逻辑。
