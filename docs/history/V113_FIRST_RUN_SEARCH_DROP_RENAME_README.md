# Yue launcher v0.1.113 更新说明

本版基于 v0.1.112，处理首次启动默认外观、搜索设置实际生效情况，以及网站拖入后的重命名流程。

## 1. 首次启动默认关闭彩虹，使用四宫格按钮

- `defaultRainbow.enabled` 改为 `false`：新用户首次启动不再默认开启彩虹总开关。
- `defaultDisplay.windowControlStyle` 改为 `pad`：新用户首次启动默认使用四宫格窗口控制按钮。
- 只修改默认值，不强行改写已有用户已经保存的彩虹或窗口按钮配置。

## 2. 搜索设置审计与修复

逐项核对了“设置 → 搜索”中的全局搜索配置与实际消费者，重点修复以下问题：

- **搜索框提示文字**：现在同时用于主界面项目搜索框和全局搜索框。此前主界面搜索框仍使用硬编码提示，因此会出现“设置里改了但主界面没变化”。
- **启用全局搜索**：关闭后 Ctrl+K 和顶部入口都不会继续打开全局搜索；如果搜索窗口已经打开，关闭设置时会同步关闭。
- **搜索路径 / 搜索网址**：两个开关现在真正独立。网址项目只受“搜索网址”控制，文件/文件夹等项目路径只受“搜索路径”控制。
- **包含系统工具**：关闭后会完整排除内置系统工具父目录及其子目录、项目和相关命令，不再只过滤部分 `.msc/.cpl/System32` 条目。
- **包含便签**：关闭后既不返回便签正文，也不再把便签目录作为目录结果残留出来。
- **最近使用优先**：关闭后不再叠加使用次数或最近使用时间的排序权重。

同时复核以下搜索设置仍有对应运行逻辑：最大结果数、项目图标显示、图标大小、图标解析模式、图标并发数、父/子目录路径显示、完整路径显示、匹配高亮、名称/父目录/子目录搜索、设置/命令/目录结果、拼音、结果类型、Enter 与 Ctrl+Enter 动作。

## 3. 网站拖入默认显示重命名界面

- 新增行为设置 `promptRenameDroppedWebsite`，默认值为 `true`。
- 从浏览器拖入网页链接，或拖入 `.url/.website` 文件时，默认先弹出应用内“重命名网站”界面。
- 用户确认的新名称会作为最终项目名称；取消时保留当前浏览器名称或域名。
- 开启重命名提示时，后台网页标题解析不会再覆盖用户刚输入的名称。
- 可在 **设置 → 拖动 → 拖入网站后显示重命名界面** 关闭；关闭后恢复为直接添加，并沿用原有自动标题解析逻辑。
- 新设置已加入设置搜索索引，可搜索“网站、拖入、重命名、URL、浏览器”等关键词定位。

## 兼容性

- 配置 schema 从 20 升至 21。
- 旧配置没有 `promptRenameDroppedWebsite` 字段时会自动按 `true` 处理，因此升级后默认启用网站拖入重命名。
- 已显式关闭该设置的配置会保持 `false`。
- v0.1.112 的托盘隐藏、任务栏隐藏及窗口恢复修复保持不变。
