# v86 设置界面排版与简洁模式

本次针对设置界面的字体溢出、内容偏左和说明文字过多进行优化。

## 修改内容

1. 体验页的分段按钮不再拆字换行，“保持显示 / 最小化 / 隐藏到托盘”会保持完整文字。
2. 体验页各设置卡片与拖动页一样在内容区水平居中，窄宽度下自动改为上下布局。
3. 在“设置 - 体验 - 页面与设置记忆”增加“显示设置描述”开关。
   - 开启：显示辅助说明。
   - 关闭：隐藏辅助说明，只保留设置名称和控件。
4. 精简体验页和拖动页的长说明，减少视觉负担。
5. 设置搜索支持“描述 / 简洁 / 辅助说明”等关键词。
6. 增加键盘焦点描边，分段选择按钮增加 `aria-pressed`，提升键盘操作和可访问性。
7. 选项区使用容器宽度响应式布局，而不是只依赖整个窗口宽度，缩放或窄面板下更稳定。

## 配置兼容

新增配置项：`experience.showSettingsDescriptions`。

旧配置读取时默认开启说明文字，不会改变现有用户的显示习惯。
