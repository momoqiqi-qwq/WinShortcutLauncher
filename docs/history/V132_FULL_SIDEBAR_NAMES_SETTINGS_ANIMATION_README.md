# V132 版本说明：完整子目录名称 · 设置打开防跳动 · 设置分类切换动画

本版本包含 3 项改动：1 项新功能（完整显示子目录名称）、1 项修复（每天第一次打开设置跳动）、1 项新功能（设置分类切换动画，可关闭）。版本号 0.1.131 → 0.1.132。

## 1. 完整显示子目录名称（新功能）

左侧“子目录”面板中的名称此前始终按“子目录名称行数”（1–4 行）截断省略。新增开关后可选择完整换行显示，长名称不再出现 “...” 省略。

入口（两处，随时切换）：

- 侧栏空白处 / 主内容区空白处右键菜单 → “完整子目录名称”（位于“子目录列数”下方，开启后显示 ✓）。
- 设置 → 字体 → “子目录名称显示” → “完整显示子目录名称”。

行为细节：

- 开启后子目录卡片高度随名称自动增高，多列布局下每列宽度不变。
- 设置搜索中可搜到“完整显示子目录名称”，搜索结果里带可直接修改的开关。
- 该开关属于空白处右键菜单项目（id：`sidebarFullNames`），可在“设置 → 右键菜单 → 空白处”中隐藏/恢复。

实现：`display.sidebarShowFullNames`（默认关闭）；`Sidebar.tsx` 根据开关给 `.sidebar-tabs` 加 `full-names` 类，`Sidebar.css` 中取消 `-webkit-line-clamp` 截断。

## 2. 每天第一次打开设置跳动（修复）

原因：`SettingsPanel` 常驻挂载（关闭时仅返回 null），面板位置/尺寸状态只在首次挂载时初始化，且初始化固定读取 localStorage 中记忆的旧 rect。自适应尺寸模式下，打开后的第一个 effect 会立刻把 rect 纠正为自适应值——第一次打开设置（通常是每天第一次）就会看到窗口位置/尺寸跳一下；同一天内后续打开复用已纠正的状态所以无感。

修复（`useSettingsPanelLayout.ts`）：

- rect 初始化按当前模式惰性计算：自适应模式用自适应 rect、固定不记忆模式用默认居中 rect、记忆模式才读 localStorage，首帧即正确。
- 滚动位置恢复由 rAF 改为 `useLayoutEffect` 同步执行，在首帧前定位到记忆滚动位置，不再出现“先在顶部、下一帧跳到记忆位置”。
- 溢出检测（滚动保护类名）同步执行一次，类名在首帧前生效。
- 顺带修正：打开面板时不再用 0 覆盖“记住每个设置分类的滚动位置”里当前分类的记录（此前每次打开都会把当前分类的记忆滚动位置清零）。

## 3. 设置分类切换动画（新功能，可关闭）

切换左侧设置分类时，内容区使用 190ms 淡入 + 上滑过渡（与 v131 折叠展开动画同曲线），替代原来的瞬时切换。

- 开关位置：设置 → 体验 → “项目交互与动画” → “设置分类切换动画”（默认开启）。
- 关闭后立即切换；开启“减少动画”时自动禁用。
- 设置搜索可搜到“设置分类切换动画”。

实现：`experience.settingsTabAnimation`（默认开启）；`SettingsPanel.tsx` 给内容包一层 `key={activeTab}` 的 `.settings-tab-pane`，`Settings.css` 新增 `settings-tab-enter` 关键帧；`.settings-content >` 相关选择器已兼容新包装层。
