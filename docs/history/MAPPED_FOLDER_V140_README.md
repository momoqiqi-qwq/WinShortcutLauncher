# 映射文件夹子目录 V140（自选文件夹实时镜像）

## 需求

在 V139「开始菜单子目录」的基础上，把「镜像一个真实文件夹」这个能力**泛化**：
让用户自己选任意一个文件夹作为镜像目标，拖入应用就在**那个文件夹**里生成快捷方式。

即：开始菜单子目录 = 根目录写死的镜像目录；映射文件夹子目录 = 根目录用户自选的镜像目录。

## 五类子目录的差别

| 类型 | 内容来源 | 拖入的后果 | 每个父目录上限 |
| --- | --- | --- | --- |
| `normal` | 配置（`items`） | 存进启动器配置 | 不限 |
| `all` | 配置（全量视图） | 存进启动器配置 | 1 |
| `notes` | 配置（便签） | 存进启动器配置 | 1 |
| `startMenu` | **实时读系统开始菜单文件夹** | **在系统开始菜单里生成 `.lnk` / `.url`** | 1 |
| **`mapped`** | **实时读用户自选的文件夹** | **在所选文件夹里生成 `.lnk` / `.url`** | **不限** |

`startMenu` 与 `mapped` 共用同一套「镜像目录」语义：**内容不落盘**（条目由 Rust 实时扫描，
只活在运行时 store 里），**写入落到真实文件夹**，**删除送回收站**，**重命名改真实文件名**。
区别只有两点：

| | `startMenu` | `mapped` |
| --- | --- | --- |
| 根目录 | 写死 `%APPDATA%\…\Start Menu\Programs` | 用户创建时自选，存在 `directory.mappedPath` |
| 条目过滤 | `EntryFilter::ShortcutsOnly`（只认 `.lnk`/`.url`/`.exe`） | `EntryFilter::All`（文件 + 文件夹全部显示） |

## 创建流程

1. 空白处右键 →「新建子目录」→「映射文件夹子目录」
2. 弹出文件夹选择框，选一个文件夹（**取消 = 整个创建中止**，不会留一个空壳子目录）
3. Rust 侧 `validate_mapped_folder` 校验该路径存在且是目录，通过后才建子目录
4. 子目录名默认取所选文件夹的**最后一段名**（可随后双击重命名，只改配置里的显示名，
   不影响被镜像的文件夹）

## 目录行为

- 扫描：**只扫根目录一层**，不递归子文件夹
- 镜像：**实时**。在外部往那个文件夹里丢文件，切回该子目录（或点刷新）即可看到
- 可建**多个**映射子目录，各镜像各自的文件夹；条目按 `directoryId` 分组存储
- `directory.mappedPath` 随配置持久化（重启后知道该扫哪里）；条目本身仍不落盘

## 拖入的写入规则

| 拖入的东西 | 结果 |
| --- | --- |
| `.lnk` / `.url` | **原样复制**到所选文件夹 |
| `.exe` / 文件夹 / 其它文件 | 用 `WScript.Shell` 生成**指向它**的 `.lnk`（并设 `WorkingDirectory`） |
| 网址（拖链接） | 写成 `.url` 文件（`[InternetShortcut]` 格式） |
| 已在所选文件夹内的路径 | 自动跳过，不重复写入 |
| 重名 | 自动加 ` (2)`、` (3)` 后缀 |

## 右键菜单行为

- **子目录上**：
  - 「刷新映射文件夹」——立即重扫
  - 「打开映射文件夹」——在资源管理器里打开被镜像的文件夹
  - 「重新选择文件夹」——换一个目标文件夹，选完立即重扫
  - 「清空子目录项目」「粘贴项目」「添加系统功能」**禁用**（内容由真实文件夹决定，不能从配置侧清空）
  - 「便签 / 普通切换」**隐藏**，且该子目录不参与「合并到全部」
- **条目上**：菜单作用于**真实文件** —— 重命名改真实文件名（保留原扩展名），
  删除送**回收站**（可恢复）；固定、图标编辑、文字显示、复制/移动到目录等
  只影响配置的操作在该目录下隐藏

## 安全边界

删除 / 重命名前都会先 `ensure_inside(root, target)` 校验目标确实位于**该子目录所映射的文件夹**内，
越界直接拒绝。比较时统一小写、统一分隔符、剥掉 `canonicalize()` 带来的 `\\?\` 前缀，
并**带上路径分隔符比对** —— 否则 `…\Prog2\x` 会被误判成在 `…\Prog` 内。

## 已知限制

1. 扫描不递归子文件夹（只展示所选文件夹的根级条目）
2. **内拖不生效**：把启动器里已有的项目拖到映射子目录上，不会写回真实文件夹
   （只有从外部拖入的文件/文件夹/网址才会）
3. `WScript.Shell` 建 `.lnk` 与回收站删除两条分支**未做运行时验证** ——
   本沙箱硬拦 COM 实例化 / `Add-Type` / 回收站 API，只做了静态审查 + 路径护栏独立 `rustc` 编译验证
