# v0.1.103 导入中心 + 自由快捷设置 + 设置搜索

## 这一版解决什么

v0.1.103 基于本次会话中实际可读取的 v0.1.100 源码整合实现，目标是把高频设置和外部数据导入做得更可控，同时避免继续把新逻辑堆进原有超大组件。

## 1. 安全导入中心

- Lucy `link.db`、Maye/Maya JSON/JDB 都先进入预览，不会选完文件立即覆盖。
- 两种导入方式：
  - **智能合并**：保留当前应用设置，只合并目录、项目和便签数据。
  - **完全覆盖**：使用导入文件替换当前配置，执行前二次确认。
- 预览会显示：新增父目录、新增子目录、新增项目、完全重复、需要决定的冲突。
- 冲突支持三种策略：**保留当前 / 使用导入 / 两个都保留**；可批量设置，也能逐项修改。
- 路径/URL 做规范化比较：Windows 路径忽略大小写并兼容 `/` 与 `\\`；URL 会做基础规范化。
- 合并目录时主要按用户可见名称和真实路径/URL 判断，不依赖 Lucy/Maye 外部 ID。
- 导入过程中保持设置窗口打开，避免导入完成后把用户从当前工作流中弹走。

## 2. 导入前自动回滚快照

- 每次真正导入前保存一份完整的“导入前快照”。
- 优先存入 **IndexedDB**，减少图片/图标较多时撞到 `localStorage` 容量上限的概率。
- IndexedDB 不可用时退回 `localStorage`。
- 如果两种存储都失败，本次导入会取消，不会在无备份状态下继续。
- 数据设置页增加“回滚上次导入”，展示快照时间和来源文件。

## 3. Maye JDB 不再执行 JavaScript

原导入路径为兼容 JDB 使用动态 `Function(...)`。v0.1.103 改成 `safeJdbParser.ts` 静态解析器：

- 支持常见静态对象语法：对象、数组、单双引号字符串、数字、布尔值、`null`、注释、未加引号的普通键、尾逗号。
- 支持 JDB 赋值前的空白、单行/块注释。
- 拒绝函数调用、成员访问、模板字符串和其他可执行表达式。
- 拒绝 `__proto__`、`prototype`、`constructor` 等危险键，降低原型污染风险。
- 整个解析流程不会调用 `eval` 或 `Function`。

## 4. 20 个自由快捷设置入口

快捷设置从固定入口升级成可配置目录，共 20 项，覆盖：主题、主背景、设置背景、界面布局、字体、图标、彩虹、操作、拖动、窗口、快捷键、导航、右键菜单、便签、搜索、文件中转、图片预览、体验、自检、数据与导入。

支持：

- 拖动自由排序；
- ⭐ 收藏，高频入口优先；
- 隐藏不需要的入口，并可恢复；
- 一键恢复默认布局；
- 新版本新增入口时，在保留用户顺序的同时自动补入；
- 配置持久化；
- 键盘方向键 / Home / End / Esc；
- 响应“减少动态效果”。

为了降低 `TopBar.tsx` 继续膨胀的风险，菜单已拆成 `QuickSettingsMenu.tsx` + 独立 CSS，目录定义/偏好逻辑放在 `lib/quickSettings.ts`。

## 5. 搜索具体设置并跳转高亮

原设置搜索更接近“筛分类”。现在新增细粒度设置索引：

- 可直接搜索“贴边、回滚、背景、字体、快捷键、行号、自动保存、右键菜单”等具体项；
- 搜索结果在设置内容区显示，不挤在窄侧栏中；
- 点击结果自动切换对应分类/子区块；
- 等待折叠区展开后滚动到目标附近并短暂高亮；
- “减少动态效果”开启时取消平滑位移和大部分过渡。

2. Maye JDB：普通文件、带前导注释、单引号、尾逗号；恶意函数表达式应明确拒绝。

4. 三种冲突策略分别对项目、便签、目录类型做一次回归。
5. 快捷设置拖动、收藏、隐藏、恢复默认后重启，确认偏好仍在。
6. 设置搜索跳转到折叠区内部项目，确认展开、定位、高亮正确。
