# Yue launcher v81：设置自适应、右键菜单分类与详细自检

## 1. 设置窗口自动适配

“设置 - 界面 - 设置窗口大小”新增：

- 自动适配 exe 主界面大小。

开启后：

- 设置窗口会根据当前主窗口可用宽高自动计算大小；
- 主窗口缩放时设置窗口同步调整；
- 会考虑“设置界面缩放”比例，避免放大后超出窗口；
- 自动适配期间关闭自由拖动和边框缩放。

关闭后：

- 恢复自由拖动和右下角缩放；
- 可继续使用“记住设置窗口大小和位置”。

## 2. 设置 - 右键菜单

新增独立分类，并分成：

- 子目录；
- 父目录；
- 空白界面处。

每个分类都可以：

- 单独显示或隐藏功能；
- 全部显示；
- 应用常用精简布局；
- 恢复默认布局。

菜单中的分隔线会根据当前可见功能自动生成，避免隐藏功能后出现连续空分隔线。全部隐藏时会显示恢复提示。

## 3. 详细自检与一键跳转

自检问题现在支持展开，逐项显示：

- 父目录；
- 子目录；
- 项目；
- 路径或网址；
- 具体异常原因。

点击“跳转”后会关闭设置，进入对应父目录/子目录并选中项目，同时平滑滚动到可见位置。

支持的详细问题包括：

- 重复 ID；
- 空名称；
- 空路径；
- 异常网址；
- 重复路径；
- 缺失图标。

复制诊断摘要时也会包含详细位置。

## 4. 兼容与迁移

- 程序版本：0.1.81；
- 显示版本：v81；
- 配置持久化版本：12；
- 旧配置会自动补齐设置窗口自适应和三类右键菜单字段。
