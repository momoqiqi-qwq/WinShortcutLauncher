# v60 拖出屏幕回弹流畅动画

本版继续在 v59 基础上修改：

1. 窗口拖出屏幕弹回时增加流畅动画
   - 在“设置 - 窗口行为”新增“拖出屏幕弹回时使用流畅动画”。
   - 开启后，窗口从屏幕外弹回屏幕内时会平滑滑回，使用带轻微回弹感的曲线。
   - 关闭后，窗口会立即回到屏幕内。

2. 新增回弹动画时长设置
   - 在“设置 - 窗口行为”新增“弹回动画时长”。
   - 可调范围：80ms - 600ms。
   - 默认 220ms。

3. 原逻辑保留
   - “窗口拖出屏幕时弹回屏幕内”仍然控制是否启用拖出屏幕弹回。
   - 鼠标仍在 exe 界面内时，不触发隐藏。
   - 底部贴边反复隐藏/弹出修复继续保留。

- 程序版本：0.1.60
